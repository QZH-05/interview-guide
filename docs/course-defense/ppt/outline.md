## 2. 逐页大纲

### 第 1 页 · 封面（0:20）

- 标题：AI 面试平台的网络规划与部署
- 副标题：基于 eNSP 的校园网与数据中心半实物仿真
- 底部：姓名 / 学号 / 指导教师（**记得替换占位符**）

**口播**：问好 + 一句话说明"把真实的 AI 应用放进 eNSP 网络里做规划和验证"。

---

### 第 2 页 · 选题背景（0:50）

- 左：业务特征（实时语音 / 流式回答 / 大文件与 AI 调用）
- 右：三个要求 → 本课题落点 → 证据

**口播**：先讲业务为什么对网络有要求，再对齐老师的三个要求。
**强调**：不是"套壳"，三者串在同一条链路上。

---

### 第 3 页 · 应用侧架构（0:50）

- 浏览器 → Nginx:80 → Spring Boot:8080 → PG / Redis / MinIO / LLM
- 左下：关键协议（REST、WebSocket、SSE、S3、Redis Stream）

**口播**：每一跳用什么协议，为后面的抓包埋伏笔。

---

### 第 4 页 · 网络需求分析（0:40）

- 四张卡片：时延、带宽、安全、可用性
- 每张卡片：目标值 + 不满足会怎样

**口播**：先定指标，再定方案；后面的设计都是围绕这四个目标。

---

### 第 5 页 · 网络拓扑（1:20）

- 四层：出口（R1）、核心（CORE）、接入（ACC1/ACC2）、DMZ
- 右侧：真实主机 10.20.0.10 + Cloud 桥接
- 左上：设计要点（静态默认 + OSPF、VLAN 隔离）

**口播**：从外到内讲一遍，重点解释"为什么应用不跑在 eNSP 里"。
**建议**：答辩前把这张图替换成 eNSP 拓扑截图（保留右侧说明文字），更真实。

---

### 第 6 页 · VLAN 与地址规划（0:50）

- 表格：VLAN / 网段 / 网关 / 用途 / 分配方式
- 右：为什么这样分 + 地址规划原则

**口播**：广播域、安全域、故障域三个理由；网关统一放核心（SVI）。

---

### 第 7 页 · 路由与 NAT（0:50）

- 左：R1 静态默认 + 默认路由注入；CORE OSPF
- 右：NAT 示意图 + 三条验证命令

**口播**：为什么出口静态、内部动态；NAT 解决什么问题。
**可能被问**：为什么不用全部 OSPF？答：出口只有一个方向，静态更稳定、可控。

---

### 第 8 页 · 安全设计（1:00）

- 表格：80/53/ICMP 放行；5432/6379/9001 拒绝
- 右：实现方式（ACL）+ 为什么不用 USG

**口播**：最小权限 + DMZ 隔离；主动说明 ACL 是包过滤，不是状态检测。
**加分**：这里主动承认技术取舍，比被问出来好。

---

### 第 9 页 · 部署实现（1:10）

- 五步：建拓扑 → 环回网卡 → Cloud 双端口 → Compose → PC-B 接入
- 右：关键说明（eNSP 不能跑 JVM、Cloud 是二层桥接、回程路由）

**口播**：半实物仿真的核心；重点讲"主机为什么要加回程路由"。
**演示衔接**：讲完这页直接切 eNSP 和浏览器。

---

### 第 10 页 · 抓包分析（1:00）

- 三块：TCP 三次握手 / WebSocket 101 / SSE chunked
- 每块下方是截图占位框

**口播**：三张图对应三个业务场景。
**必做**：把占位框换成自己的 Wireshark 截图（带过滤条件和时间列）。

---

### 第 11 页 · 测试与验证（0:50）

- 8 行表格：DHCP、连通性、OSPF、NAT、ACL、DNS、WebSocket、SSE
- 右：QoS 对比 + 结果

**口播**：每条设计都有对应检查，不是"感觉通了"。
**注意**：如果 QoS 没做，就把右侧换成"抓包文件清单"。

---

### 第 12 页 · 总结与展望（0:20）

- 做了什么（网络 / 应用 / 验证）
- 还可以怎么做（VRRP、HTTPS、IPv6/SDN）
- 底部一句话体会

**口播**：三句话收尾，然后请老师提问。

## 6. 附录：可能被追问的 6 个问题

| 问题 | 一句话回答 |
|---|---|
| 为什么不用 USG？ | VirtualBox 与 Docker/WSL2 冲突；ACL 实现包过滤，功能覆盖，区别是状态检测 |
| eNSP 里怎么跑 Java？ | 不跑；eNSP 只做网络，应用在真实主机，Cloud 二层桥接进 DMZ |
| 为什么出口静态、内部 OSPF？ | 出口单方向、静态稳定；内部多 VLAN、需要扩展和自动收敛 |
| NAT 后怎么拿真实 IP？ | X-Forwarded-For，但只信任可信代理，否则可伪造 |
| WebSocket 和 HTTP 什么关系？ | HTTP Upgrade 握手后升级为全双工，仍跑在同一条 TCP 上 |
| 单点故障怎么办？ | 双核心 VRRP + 链路聚合 + OSPF（选做方案已写） |
